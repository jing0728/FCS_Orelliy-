# FCS 产品图片对比

公开产品对比页面与报告。以 FCS 型号为基准，分别展示 MP、Monroe、KYB 的图片、360°旋转序列及对比说明。

网站地址：https://jing0728.github.io/FCS_Orelliy-/

## 已收录系列
- DMA 4 to FCS 1：8 个 FCS 型号
- DMA 3 to FCS 2：2 个 FCS 型号
- DMA 3 to FCS 1：4 个 FCS 型号
- DMA 2 to FCS 2：20 个 FCS 型号

DMA 2 to FCS 2 为第三批的20个型号，不代表原表中该family的全部型号。

## 使用
- 在线打开首页，可按 FCS、MP、Monroe 或 KYB 型号搜索。
- 红框标出照片中的对照位置。仅有静态图的型号不会模拟360°。
- 旋转、自动播放和滑条均只控制所在卡片的图片。
- 离线使用请下载同组完整分享包，完整解压后打开 Excel 或 index.html。
- 颜色差别忽略；缺图与没有明显差别分开标注。
- 对应号必须按车型年份、发动机、驱动、变速箱及悬挂配置核对。图片比较不等同于适配认证。

原始输入压缩包、备份文件和内部工作脚本未放入本仓库。完整表格及对比资料由仓库所有者公开分享。
